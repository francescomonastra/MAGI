ML4ASTRO3 flash talk **1 Sep 2026**. Today: 20 Jul → ~6 weeks.

## 0. The risk framing (read first)

The mixture head is a real change with its own re-validation, on a loaded 6-week
path. Hold "low-risk beta" and "mixture head" together like this:

- Ship behind a flag: `energy_mode ∈ {"categorical", "quantfix", "mixture"}`.
  - `categorical` = current v0.7.2 behaviour (default until mixture is validated).
  - `quantfix`  = the **config-only quick fix** (no smoothing on line bins,

    This is the **guaranteed fallback** — land it first so the beta always has
    *some* line improvement.
  - `mixture`   = the new continuum + line-mixture head (target).
- **Go/no-go date: ~15 Aug.** If `mixture` isn't converging + validated by then,
  the beta ships `quantfix`. Non-negotiable, protects the release + talk.
- Diagnose before building: run `tools/energy_line_diagnostic.py` on the real
  spectrum + trained model to confirm which mechanism (A label-smoothing /
  B temperature / C in-bin) dominates and quantify the expected gain.

## 1. The mixture-density energy head (spec)

Model, in a transformed energy space `y = T(E)` (T = log or QuantileTransformer,
consistent with the geometry-feature philosophy):

```
p(y | z, cond) = π_0 · N(y; μ_c(h), σ_c(h))         # continuum
               + Σ_{l=1}^{L} π_l · N(y; T(μ_l), σ_l)  # one narrow comp per known line
```

- `h = energy_branch(stem)` (existing features).
- Component gate: `π = softmax(Dense(L+1)(h))` — still a small categorical, but over
  `{continuum, line_1..L}`, NOT hundreds of bins. Each line gets a **protected,
  directly-learned firing rate**, which is what fixes "lines generated lower".
- Continuum: `μ_c, σ_c = Dense(1)(h)` each (like the `ur/uv/phi` Gaussian heads).
- Lines: `T(μ_l)` FIXED from physics (known decay energies); `σ_l` fixed at
  detector resolution in y-space (or a single learned scalar). Model only learns
  `π_l`. Whole mixture lives in y-space → no per-sample Jacobian beyond the one
  `T` applied to data once.

Line list is an INPUT — supply the physical line energies for the CryoSphere
background (e.g. K-40 1460.8 keV, Bi-214/Pb-214 lines, Tl-208 2614.5 keV, …) from
the GPS spectrum / background components used to make the training data.

## 2. Files to change (all localized to the energy path)

- `core/model.py` (`CVAE_CatEnergy_ContPhi_TaskAdaptive`):
  - `__init__`: add `energy_mode`, `line_positions_y`, `line_sigma_y`, `n_lines`;
    build the gate + continuum heads when `energy_mode=="mixture"`.
  - `_decode_params`: emit `energy_gate_logits`, `energy_cont_mu`, `energy_cont_logsigma`.
  - `_reconstruction_terms`: replace `energy_ce` with `energy_mixture_nll` (below).
  - `generate`: sample component ~ Cat(π); continuum → N(μ_c,σ_c), line → N(T(μ_l),σ_l);
    then invert T. Remove the categorical-idx + `energy_from_idx(uniform)` path when mixture.
- `core/losses.py`: add `gaussian_mixture_nll(y, gate_logits, comp_mu, comp_logsigma)`
  (log-sum-exp over components). Keep `smoothed_categorical_ce` for `categorical` mode.
- `data/preprocessing.py`: build/fit `T` for energy; map line energies → y-space;
  persist transform (joblib) + line params (metadata).
- `generation/sampling.py` + `generation/reconstruction.py`: mixture sampling +
  inverse-T path; keep `energy_from_idx` for legacy modes.
- `training/checkpointing.py`: persist an `"energy_head"` block (mode, n_lines,
  line_positions_y, line_sigma_y, transform id) in `*_metadata.json`, and ADD a
  load-time assertion that the saved energy-head config matches the constructed
  model (kills the known train↔generate string-key drift).

## 3. The config-only quick fix (`quantfix`, the fallback) — do this FIRST

No architecture change; three edits, all in the existing categorical path:
1. Do NOT apply label smoothing to line bins (or set `smoothing=0` for line bins).
   `smoothed_categorical_ce` local-neighbor mode caps a pure line target at (1−s).
2. `energy_sampling_temperature ≤ 1.0` (T>1 flattens peaks).
3. For line bins, replace `energy_from_idx(mode="uniform")` with a delta /
   detector-resolution draw at the physical line energy (stops the in-bin smearing
   that the diagnostic shows can cut a peak to ~bin/(2·res) of a delta).
